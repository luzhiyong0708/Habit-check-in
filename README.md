# 习惯打卡

一个可以装到手机桌面、像小程序一样点开就用的习惯打卡应用。没有服务器、没有账号，数据全部保存在使用者自己的设备里。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面 |
| `app.css` / `app.js` | 样式与逻辑 |
| `sw.js` / `manifest.webmanifest` | 离线缓存与「安装到桌面」 |
| `icons/` | 应用图标 |
| `server.js` / `启动手机版.cmd` | 让手机通过 Wi-Fi 打开的本地小服务器 |

## 在手机上使用

### 方式一：先用 Wi-Fi 试（最快）

1. 手机和这台电脑连同一个 Wi-Fi。
2. 双击 `启动手机版.cmd`，窗口里会列出形如 `http://192.168.x.x:8080/` 的地址。
3. 手机浏览器打开这个地址即可（首次运行 Windows 可能弹出防火墙询问，选「允许」）。

注意：这种方式要靠电脑开着才能打开，适合先看看效果。

### 方式二：放到网上，装成 App（推荐日常使用）

放到任意支持 HTTPS 的静态托管上就能「安装到桌面」并离线使用，例如 GitHub Pages：

1. 注册 GitHub 账号，新建一个 Public 仓库。
2. 把这个文件夹里的所有文件上传上去。
3. 仓库 Settings → Pages → Source 选 `main` 分支、根目录，保存。
4. 等一两分钟，访问 `https://你的用户名.github.io/仓库名/`。
5. 手机打开这个网址：
   - iPhone：Safari「分享」→「添加到主屏幕」
   - Android：浏览器菜单 →「安装应用」或「添加到主屏幕」

之后从桌面图标打开就是全屏应用的样子，没网也能用（Service Worker 会缓存页面）。

> 换网址等于换了一份存储空间，旧数据不会自动跟过去。换地址前先在「使用者」面板里导出备份，到新地址再导入。

## 多人使用

点右上角的使用者头像可以新建、切换、重命名、删除使用者：

- **同一台手机/平板多人共用**：每人一个使用者，习惯、打卡记录、连续天数完全独立，面板里还能一眼看到每个人今天完成了几项。
- **各自用自己的手机**：把网址发给对方，各自打开即可，数据天然各存各的手机里，互相看不到。

如果想让多人打卡进同一份数据、互相可见，那就需要一个联网的服务器来同步，当前的「数据只存本地」方案做不到。

## 数据与备份

- 数据保存在浏览器的 `localStorage`，键名 `habit-tracker-v2`，只在本机，不会上传。
- 清除浏览器数据 / 站点数据会一并清空记录；换浏览器、换设备也不会同步。
- 「使用者」面板底部有**导出备份 / 导入备份**（JSON 文件），换手机、换网址、怕丢数据时用它搬运和留底。
- 老版本（`habit-tracker-v1`）的单档案数据会在第一次打开时自动升级为「我」这个使用者，原数据不会被删除。

## 功能

- 顶部显示「今日完成 X / Y 项」和进度条、当前使用者。
- 点一下圆圈就打勾，每个习惯各自显示连续天数「🔥 N 天」。
- 点「编辑」进入编辑态：调整顺序（↑ ↓）、重命名、删除；点「完成」退出。编辑态下点圆圈依然可以打勾。
- 删除习惯后，今天的清单不再包含它，但过去几天的历史照旧保留。
- 「最近 14 天」记录每天的完成情况，点一天可以看到当天具体完成了哪几项，从最早创建习惯那天开始列。

## 开发/自测

- 直接双击 `index.html` 也能用（离线、单机），只是没有离线缓存和安装能力。
- 本地起服务：`node server.js`（端口可用环境变量 `PORT` 调整）。
